# mncord sounds (© mnlovo)

Drop files here named exactly like this (`.ogg`, `.wav` or `.mp3`, 48 kHz, under 2 s, ringtones can loop):

join · leave · mute · unmute · deafen · undeafen · message · mention · ring_in · ring_out · call_end ·
stream_start · stream_stop · ptt_on · ptt_off · disconnect · reconnect · startup

Missing files fall back to a short synthesized tone (see `app/sounds.ts`). Only use sounds you own or have a licence for.
