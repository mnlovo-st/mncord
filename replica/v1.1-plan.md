# v1.1 requests (owner, 2026-11-25)

1. Email verification is mandatory: after sign-up nothing works until the 6-digit code is entered.
2. Owner approval: after verifying, a new account waits for the owner's one-time approval. Until then the
   app shows the animated mnlovo logo + "Waiting for approval" text (EN/AR) and a "Check again" button.
   - Owner = OWNER_EMAIL (Worker var/secret) if set, otherwise the first account ever created.
   - Owner sees pending accounts in Settings → Approvals (approve / decline) and gets a live notice.
   - Server: users.approved_at; every API route except auth/@me/verify/approval-status refuses with
     403 approval_pending; the gateway refuses to identify until approved.
3. Full profile editing: display name, pronouns, about me, avatar, banner, profile colour, custom status.
4. Language: English by default. Arabic changes the words only; the layout stays left-to-right (server
   rail and sidebars stay on the left), Arabic sentences still read correctly (bidi plaintext).
5. Discord-like top bar: centred title of where you are, drag area, our own minimise/maximise/close.
6. Primary buttons blue (from the logo) instead of amber.
7. Home (direct messages) button: Discord-style blue squircle with a white "M" glyph.
8. Feel as close to Discord as possible (spacing, hover, rail, pills).
